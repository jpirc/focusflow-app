# Quick Edit Guide - ADHD-Friendly Task Editing

FocusFlow now features **ultra-fast inline editing** designed specifically for ADHD users. Update tasks in **1-2 clicks** instead of 4+.

## 🎯 Design Philosophy

- **Fewer clicks** - Direct manipulation, no modals for simple edits
- **Immediate feedback** - Changes save automatically
- **Clear affordances** - Visual hints show what's editable
- **Undo-friendly** - Easy to reverse mistakes
- **No mode switching** - Stay in flow, avoid context switching

## ⚡ Quick Actions

### Double-Click Title to Edit
- **Action**: Double-click any task title
- **Result**: Inline text editor appears
- **Save**: Press `Enter` or click away (auto-save on blur)
- **Cancel**: Press `Esc` or click ❌
- **Why**: Most common edit, should be fastest

### Click Badges to Change
No menu diving - just click the badge you want to change:

#### Priority Badge
- **Click** the current priority (Low/Medium/High/Urgent)
- **Select** from dropdown
- **Result**: Instant update, no confirmation needed

#### Time Block Badge  
- **Click** the time block (Morning/Afternoon/Evening/Anytime)
- **Select** from dropdown
- **Result**: Task moves immediately

#### Energy Level Icon
- **Click** the battery icon (Low/Medium/High energy)
- **Select** from dropdown
- **Result**: Energy requirement updates instantly

### Hover Quick Actions
When you hover over a task, quick action buttons appear:

- **✓ Complete** - Mark task done instantly
- **🗑️ Delete** - Remove task (with confirmation)
- **⋯ More** - Opens menu for advanced actions

### Advanced Editing (Full Modal)
For complex changes, use the full edit modal:
- **Click** the **⋯ More** button
- **Select** "Full Edit"
- **Access**: Subtasks, dependencies, description, AI breakdown

## 🎨 Visual Hints

### "Double-click to edit" Tooltip
Appears on title hover (non-completed tasks)

### Cursor Changes
- **Text cursor** on title (editable)
- **Pointer cursor** on badges (clickable)
- **Grab cursor** on card (draggable)

### Badge Hover States
Badges brighten on hover to show they're clickable

## 📱 Mobile Considerations

On mobile/touch:
- Single tap opens dropdown menus (no hover state)
- Long-press title to edit (instead of double-click)
- Drag handles remain visible

## 🔥 Power User Tips

### Keyboard Shortcuts (in edit mode)
- `Enter` - Save title edit
- `Esc` - Cancel title edit
- `Tab` - Move to next field (in full modal)

### Batch Editing
For multiple similar changes:
1. Open first task's badge dropdown
2. Make selection
3. Repeat on next task
4. Dropdowns stay at mouse level for rapid clicking

### Undo Mistakes
- Badge changes: Click badge again, select previous value
- Title edits: Double-click → `Ctrl+Z` (undo in text field)
- Accidental deletes: Check "Done" section, click Restore

## 🚫 What CAN'T Be Quick-Edited

These require the full modal:
- **Subtasks** - Managing list of subtasks
- **Dependencies** - Setting task dependencies
- **Description** - Long-form text
- **AI Breakdown** - Generating subtasks with AI
- **Project assignment** - Changing project (uses full modal)

## 💡 Examples

### Quick Morning Triage (3 tasks in 10 seconds)
1. Double-click "Review emails" → Type "Review urgent emails" → Enter
2. Click "Medium" badge on second task → Select "High"
3. Click "Anytime" badge on third task → Select "Morning"

### Reprioritize When Energy Drops
1. Hover task → Click battery icon → Select "Low"
2. Click "Afternoon" time block → Select "Evening"
Done in 2 seconds!

### Clean Up Completed Tasks
1. Hover completed task → Click 🗑️
2. Confirm deletion
No need to restore first!

## 🎯 Best Practices

### DO:
✅ Double-click to edit titles quickly
✅ Use badge dropdowns for priority/time changes
✅ Save full modal for complex edits (dependencies, subtasks)
✅ Trust auto-save (changes persist on blur)

### DON'T:
❌ Open full modal just to change priority
❌ Worry about manual saving (it's automatic)
❌ Click outside accidentally (blur saves, not cancels)

## 🔧 Troubleshooting

### "I double-clicked but nothing happened"
- **Completed tasks** can't be edited (restore first)
- **Currently dragging?** Release drag, then double-click
- **Menu open?** Close menu, then double-click

### "Dropdown won't close"
Click outside the dropdown or press `Esc`

### "Changes didn't save"
Check your internet connection - changes sync to server immediately

### "I want the old menu back"
The **⋯ More** button still opens the full menu with all advanced options!
